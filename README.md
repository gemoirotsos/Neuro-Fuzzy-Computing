# Neuro-Fuzzy Computing

Coursework for the **Neuro-Fuzzy Computing** course at the Department of Electrical and Computer Engineering, **University of Thessaly**, during the Fall semester of the academic year **2024–2025**.

This repository contains three problem sets combining mathematical analysis, theoretical exercises, and Python implementations. The assignments cover neural network fundamentals, optimization algorithms, convolutional and recurrent networks, competitive learning, and fuzzy logic.

## Repository Contents

Each problem-set folder includes:

- **Assignment PDF:** The original problem statements.
- **Solutions PDF:** Solutions to all exercises in the corresponding set, including mathematical derivations, explanations, and results.
- **Python code:** Implementations and computational experiments for exercises requiring programming.

## Problem Set 1 — Neural Network Fundamentals

- Linear algebra, quadratic forms, and gradient descent.
- Discrete dynamical systems and chaotic behavior.
- Neural network responses and activation functions.
- Gradient-based learning with weight regularization.
- ADALINE networks and the Least Mean Squares (LMS) algorithm.
- Multilayer Perceptrons (MLPs), backpropagation, and function approximation.
- Effects of learning rate, network size, and initialization on convergence.

## Problem Set 2 — Optimization and Neural Network Architectures

- Conjugate Gradient and Newton's method.
- Dropout and weight pruning in MLPs.
- AdaGrad and learning-rate scheduling.
- Convolutional Neural Networks (CNNs): filtering, translation equivariance, pooling, and parameter counting.
- Computational efficiency of convolution implementations.
- Radial Basis Function (RBF) networks for classification and function approximation.
- Competitive learning and neighborhood-based weight updates.

## Problem Set 3 — Recurrent Networks and Fuzzy Logic

- CNN filter pruning using norm-based and similarity-based criteria.
- Competitive learning with adaptive biases to address inactive neurons.
- Analysis of vanishing and exploding gradients.
- Recurrent Neural Networks (RNNs) for autoregressive time-series prediction.
- Backpropagation through time and eigenvalue analysis.
- Fuzzy sets, membership values, and set operations.
- Generalized negation and multivalued logic.
- Fuzzy inference rules, including generalized modus ponens and modus tollens.

## Running the Code

Open the relevant Python script or Jupyter notebook for the exercise you want to explore. Required imports and experiment settings are provided within the corresponding files.

The solutions PDFs provide the mathematical reasoning and discussion accompanying the implementations.
